# AI Customer Success Workspace

A lightweight portfolio project demonstrating how AI can support enterprise Customer Success / Technical Support workflows.

## What it demonstrates
- Workspace adoption / usage monitoring
- Customer issue classification
- Resolution progress tracking
- Knowledge-base / archive categorization
- AI-generated customer insights
- Proactive Customer Success opportunities

## Demo
Open `index.html` in a browser.

The Case Classifier is intentionally a transparent prototype using keyword rules. It can later be connected to an LLM API for semantic classification, priority prediction, summarization and recommended next actions.

## Suggested production architecture
Customer/Case data → CRM or ticketing system → AI classification layer → dashboard → knowledge archive → CSM action.

## Portfolio note
Sample data is fictional and is included only to demonstrate the concept. No confidential customer or LSEG data is used.
